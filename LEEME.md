# 03-PROYECTO

Aquí va **todo el código del sistema Django**.

- El repositorio git se inicia en esta carpeta.
- Cada módulo es una app dentro de `apps/` (productos, inventario, ventas, clientes, proveedores, reportes, usuarios).
- Las claves y contraseñas van en `.env`, que nunca se sube a git.
- Aquí no van documentos del cliente ni archivos de diseño.
